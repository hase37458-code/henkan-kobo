ローカル処理

ファイルはサーバーに送信されません。変換はすべてこの端末のブラウザ内で行われます。

ファイルを、外に出さない。

画像・PDF・Word・動画・音声・文書ファイルの形式変換を、すべて端末内で完結。アップロード不要だから、社外秘のファイルでも安心して使えます。

その他のツール

ファイル形式の変換とあわせてよく使う、細かな変換ツールです。

Base64 変換

ファイルをBase64テキストに変換、またはBase64テキストからファイルを復元します。

Markdown → HTML

Markdown形式のテキストを、そのまま開けるHTMLファイルに変換します。

文字コードをUTF-8に変換

Shift_JIS や EUC-JP で保存された、文字化けしたテキスト・CSVファイルをUTF-8に変換します。

対応フォーマット

画像
JPG ⇄ JPEG ⇄ PNG ⇄ WebP ／ 画像 → PDF
PDF・Word
PDF → PNG・JPG・TXT・DOCX ／ DOCX → PDF・TXT
動画・音声
MP4 ⇄ WebM ／ 動画 → MP3 ／ MP3 ⇄ WAV ⇄ OGG
文書・データ
CSV ⇄ JSON ／ CSV ⇄ XLSX
その他
Base64 ／ Markdown→HTML ／ 文字コード変換

PDF・Word変換について

文字情報を中心に変換します。図表・写真・複雑なレイアウトは再現されないため、内容確認や下書き用途に向いています。PDFが複数ページの画像に変換される場合は、まとめてZIPでダウンロードされます。
